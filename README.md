# 1. 🧑🏻‍💻 Setup

```sh
# 0. clone fork project
git clone https://github.com/SeolHuiGwan9478/Oegaein-back-end.git

# 1. move target directory
cd Oegaein-back-end

# 2. build project
./gradlew build

# 3. move target directory & run server
cd build/libs
java -jar oegaein-0.0.1-SNAPSHOT.jar
```
